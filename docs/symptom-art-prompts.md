# Plant doctor symptom pictures

Pictures for the symptom tiles in the plant doctor ("Something wrong?" on each plant page).
There are 30 of them. Until a picture exists, the tile shows a plain line icon, so they can arrive in any order.

## How to use this with ChatGPT

1. Paste the **style block** below first, then one or a few of the numbered prompts.
2. Ask for **one picture per image** (no sheets or grids), square, on a **transparent background**.
3. Save each picture with the exact **file name** shown, e.g. `symptom-brown-tips.png`.
4. Upload them all to GitHub in the `sprout` repo under `assets/symptoms/` (a new branch is fine, like `art-drop`), and tell Claude. I’ll resize them and wire them in.

## Style block (paste this first every time)

```
Cute sticker-style illustration for a plant care app, matching our plant buddy art: thick dark outline, bright glossy colours, soft shading and small white highlights, friendly and clear rather than gross. Square image, transparent background, no text, no words, no letters, no labels, no border, no drop shadow. The subject is centred and fills about 80% of the frame, so it reads clearly at a small size (about 90 pixels). No faces on leaves or bugs. Where a pot shows, it is a simple rounded glossy pot without a face.
```
