# Plant doctor symptom stickers

30 individual square PNGs for the “Something wrong?” symptom tiles. Filenames follow the requested `symptom-{id}.png` contract. All images use a transparent background, thick dark outlines and glossy colors; pots, leaves and bugs have no faces. The no-growth calendar has blank pages without text.
